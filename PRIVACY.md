# Privacy

HTML Canvas Recorder runs locally as a Chrome extension.

- The extension does not send recordings, canvas frames, page content, settings, or usage data to an external service.
- Recordings are generated in the browser and saved as local downloads.
- Settings and transient recording state are stored in Chrome extension local storage.
- The extension does not collect analytics.

The requested permissions are used to find canvas elements, inject the content script, communicate with frames, manage recording state, support keyboard shortcuts, and save user settings.
